# Sistema de Cadastro

## Como executar

1. Abra a pasta no VSCode
2. Abra o terminal
3. Instale as dependências:

```bash
npm install
```

4. Execute o projeto:

```bash
npm start
```

5. Abra no navegador:

http://localhost:3000

## Funcionalidades

- Login
- Cadastro de usuários
- Tela inicial
- Cadastro de pessoas
- Banco de dados SQLite
